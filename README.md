# UDEMY-CLONE
🎓 Udemy Clone

# 📌 Description

A simple Udemy Clone website created using HTML and CSS. The project is designed to replicate the basic layout and appearance of an online learning platform.

# ✨ Features

- Navigation bar
- Course categories
- Course cards with images
- Search section
- Popular courses section
- Font symbols/icons
- Clean and organized layout

# 🛠️ Technologies Used

- HTML5
- CSS3

# 🎨 CSS Concepts Used

- Flexbox
- "display: flex"
- "justify-content"
- "align-items"
- "gap"
- Font styling
- Image styling
- Margins and padding
- Borders and spacing

# 📚 What I Learned

Through this project, I practiced creating webpage structures using HTML and improved my CSS skills by working with Flexbox, alignment, spacing, images, fonts, and icons. This project helped me understand how to create a clean and user-friendly frontend webpage.

# 🚀 Future Improvements

- Add JavaScript functionality
- Make the website fully responsive
- Add course filtering and search functionality
- Add login and registration features
